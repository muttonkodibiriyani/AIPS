  3. Expand row cap: set SHOWCASE_DEMO_ROW_LIMIT=0 for unlimited rows (heavy builds — see NODE_OPTIONS).
  4. Enterprise search: for BM25/full recall at scale, ingest with scripts/catalog_upload_presigned.py + gateway (OpenSearch).
